# Welcome to Team11_NN's AI project!

This project compares four supervised classification methods (k-NN, decision tree, random forest, and neural network) on image and sentiment datasets that were previously preprocessed to be represented by numerical feature vectors. We evaluate the models using a shared training and validation split for each dataset. For the unsupervised method, we explored k-means clustering to examine how closely groups formed from the features alone correspond to the known class labels.

### How to run the project
- Clone the project on your machine
- Verify that all data files are in the data folder, the `sentiment_train.csv` is missing from the repo. as it was too large to upload.
- Run all cells in the three main notebooks of the project:
    - `01_data_setup.ipynb`
    - `02_supervised_models.ipynb`
    - `03_clustering.ipynb`
